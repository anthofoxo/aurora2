Thumper Wiki

Welcome to the Thumper Wiki. This wiki serves as a central location for everything Thumper. This wiki specifically will contain information about internal workings of Thumper, including modding information, reverse engineering information, level creation information, etc. This will also include documentation for all the Thumper tooling.

The wiki will also archive resources where we see fit. This is to keep the resources available as long as the wiki exists.

The wiki is open-source and accepting contributions. You can fork the project and submit a PR to help improve the wiki.

The wiki is in rapid development and currently migrating the known information surrounding Thumper. While this is mostly complete, you may enounter dead links, missing information, etc. No URLs should be considered permanent at this time. Contribute or contact @AnthoFoxo via Discord to have changes submitted.

Motivation

Currently all the documentation surrounding Thumper and it's tools are scattered all over the place. A lot of which have outdated and incorrect information. This wiki will serve as a central location for all documentation surrounding Thumper. We are activly gathering all existing information and migrating to this wiki.
